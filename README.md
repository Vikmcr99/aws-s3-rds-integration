Este projeto demonstra a integração de um backend com serviços da AWS, utilizando o Amazon S3 para armazenamento de arquivos (como imagens, documentos, etc.) e o Amazon RDS para persistência de dados relacionais. A aplicação foi construída com foco em escalabilidade, segurança e boas práticas de DevOps, sendo ideal para projetos que demandam alta disponibilidade de dados e arquivos.

Tecnologias utilizadas:

Amazon S3 (armazenamento de arquivos)

Amazon RDS (PostgreSQL)

Spring Boot

JPA

REST API
